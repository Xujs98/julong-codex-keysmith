# Narrative workflow

1. Initialize the project once, then inspect `state`, the current scene, active characters, worldbooks, and beats.
2. Build or update the outline as ordered beats. Start exactly one beat before drafting.
3. Recall only relevant context. Resolve conflicting facts by preferring the most recently updated local record and note the correction in the summary.
4. Draft the requested scene in the selected viewpoint and length. Keep unresolved facts as explicit TODOs rather than silently inventing canon.
5. Save the chapter, update the scene snapshot, mark a beat done only when its objective is met, and append a summary.
6. For interactive fiction, save 3-8 concise options with `options save`; advance only after the user selects one.
7. Export a portable archive when handing the project to another workspace.
